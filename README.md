项目介绍：
基于 Spring Boot + Redis 构建的高并发本地生活服务系统，核心业务涵盖用户登录、商铺查询、优惠券秒杀、点赞关注及附近商铺搜
索。项目重点解决了高并发场景下的缓存一致性、分布式锁、异步削峰等核心工程问题。
技术栈：Java、Spring Boot、MyBatis-Plus、MySQL、Redis、Redisson、Redis Stream
技术亮点：
多级缓存架构与稳定性治理：针对商铺高频查询，实施“缓存空对象 + 布隆过滤器”防穿透，结合互斥锁与逻辑过期方案防击穿，添加
随机过期时间防雪崩。有效降低数据库压力，保障了高并发下的查询性能。
分布式锁与并发控制进阶：主导秒杀模块的并发安全设计。基于 Redis + Lua 脚本实现库存预扣减与一人一单校验，保证操作原子
性；引入 Redisson 可重入锁，应用看门狗（Watch Dog）续期机制解决业务超时释放风险，并通过 tryLock 机制防止线程自旋带来
的 CPU 飙升，杜绝超卖。
异步削峰与最终一致性：引入 Redis Stream 作为消息队列，将订单生成由同步改为异步处理，实现流量削峰；结合 Redis 的原子指
令，在本地压测下保障了秒杀接口的高吞吐与数据一致性。
无状态会话与安全鉴权：基于 Redis Token 替代传统 Session 实现无状态登录，结合双拦截器（Token 校验拦截器 + Token 刷新拦截
器）保证会话安全与登录态自动续期。
高阶数据结构与空间检索：利用 Redis 的 GEO 数据结构实现按距离排序的商铺检索；利用 Set 和 ZSet 实现点赞、关注、共同关注等
社交功能，理解 Redis 底层数据结构的应用场景
